# OnePanel_Skills

Character skills, primary/secondary professions, and weapon proficiency tracking plugin for the **OnePanel Suite**.

## Features

- **Categorized Collapsible Matrix**: Displays Primary Professions, Secondary Skills, Weapon Skills, Armor Proficiencies, and Languages in clean collapsible groups.
- **High-Contrast Progress Bars**: Status bars displaying current skill rank, maximum skill cap, and percent completion.
- **Interactive Detail Drawer**: Expandable right-hand panel displaying detailed skill descriptions, trainer hints, and crafting launcher.
- **Live Search Filtering**: Search bar to instantly locate any skill without manual scrolling.
- **OnePanel Docking**: Automatically registers into OnePanel as Tab 3 (`Skills`, Order 30).

## Dependencies

- [OnePanel](https://github.com/Nuros-WoW-Forever-Addons/OnePanel)
- [OnePanelUtils](https://github.com/Nuros-WoW-Forever-Addons/OnePanelUtils)

## Installation

Extract to your World of Warcraft AddOns directory:
```text
Interface/AddOns/OnePanel_Skills/
```
